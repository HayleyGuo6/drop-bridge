# Drop Bridge

个人跨电脑临时文件中转站。Sites 以站点所有者访问限制保护整个网站和下载接口；请保持站点为私有。

- 拖拽、多文件顺序上传，直接下载，5 秒同步。
- 总容量 100,000,000 字节、最多 500 个文件；通过数据库单语句原子预留，避免并发超额。
- 文件流式写入 R2；固定长度校验，不在 Worker 中缓冲整个文件。
- 每天北京时间 08:00 到期，下载接口拒绝过期文件；每次列表、上传或下载请求会清除到期文件。**目前没有无人访问时运行的定时后台清理任务，不能保证 08:00 物理删除。**
- 暂存文件上传失败会回收；异常中断预留在一小时后、下一次访问时回收。
- 目前为个人空间；若以后开放多人访问，必须先增加用户级数据隔离。

## 验证

已使用本地 D1/R2 对独立上传、列表、下载请求进行验证，涵盖中文文件名、100 MB 完整性、容量拒绝、过期不可下载和访问清理。`scripts/check-transfer.py` 只用于本地开发状态，不应连接生产数据库。

WebMCP 提供 list_transfer_files，未在支持该接口的浏览器环境实测。

项目脚本：dev、build、db:generate。源码及迁移随部署版本保存。
